Telegram Bot
Описание

Это Telegram бот, который я разработал в качестве студенческого проекта. Бот помогает пользователям управлять повседневными задачами через напоминания, таймеры и отслеживание дней рождения.

Проект написан на Python с использованием библиотеки pyTelegramBotAPI и базы данных SQLite.

Основные возможности

Бот разделен на пользовательскую часть и административную.

Команды

Показывает список команд с примерами.

Назад в меню

Возвращает в главное меню.

Команды
/start   - запуск бота и соглашение
/admin   - админ панель
/stats   - статистика
/users   - пользователи
/bans    - блокировки
Технологии
Python 3
SQLite
pyTelegramBotAPI
threading
pytz
Установка
Установить зависимости:
pip install pyTelegramBotAPI pytz
Указать настройки в коде:
TOKEN = "ваш_токен"
ADMIN_ID = 123456789
Запустить:
python bot.py
Как работает бот
Все данные хранятся в SQLite
При запуске автоматически создаются таблицы
Используются состояния (user_state) для обработки шагов пользователя
Фоновый поток (checker) каждые 30 секунд:
проверяет таймеры
отправляет уведомления
проверяет дни рождения
снимает блокировки
Структура базы данных

Создаются таблицы:

users — пользователи
reminders — напоминания
birthdays — дни рождения
timers — таймеры
bans — блокировки
admin_logs — действия администратора
Ограничения
SQLite плохо масштабируется при большом количестве пользователей
Удаление напоминаний пока не реализовано
Нет редактирования напоминаний
Возможны задержки при высокой нагрузке
